# 🎭 Curtain Call - 무대 위 감동을 내 손 안에

## 📌 프로젝트 소개

**Curtain Call**은 뮤지컬 정보를 탐색하고, 관극 기록과 리뷰를 관리할 수 있는 뮤지컬 정보/리뷰 플랫폼입니다.

**공연·배우 정보**를 자유롭게 탐색하고, 

커뮤니티에서 **다른 관람자들과 소통**하고

리뷰와 좋아요를 기반으로 한 **개인화된 통계**를 확인할 수 있습니다.

### 💡 우리가 집중한 것

| 핵심 가치 | 설명 |
| --- | --- |
| **정확하고 풍부한 정보** | Python 크롤러로 공연, 배우, 극장 정보를 수집하고 검수하여 신뢰도 높은 데이터베이스를 구축했습니다. |
| **소통 중심의 커뮤니티** | 리뷰, 평점, 자유게시판, 찜하기 등 다양한 기능으로 사용자의 적극적인 참여와 소통을 유도합니다. |
| 다양한 관람기록 제공 | 사용자의 리뷰를 캘린더, 카드 등 여러 방식으로 제공하고, 분석하여 다양한 통계를 제공합니다.  |

## 🎯 타겟 사용자

| 사용자 유형 | 문제점 | Curtain Call의 해결책 |
| --- | --- | --- |
| **1️⃣ 뮤지컬 입문자** | "어떤 공연을 봐야 할지 모르겠어요" | 인기 순위, 사용자 평점 및 리뷰 기반 추천, 상세한 공연 정보 제공 |
| **2️⃣ 뮤지컬 매니아** | "공연 기록을 남기고 소통하고 싶어요" | 리뷰 및 별점 작성, 자유게시판을 통한 토론, 다른 사용자와의 소통 |
| **3️⃣ 정보 탐색가** | "출연 배우, 공연 장소 정보가 궁금해요" | 배우 필모그래피, 공연장 정보 등 크롤링 기반의 상세 데이터베이스 제공 |

## ✨ Curtain Call 핵심 가치

- **🌐 정보의 중앙화**
    
    공연·배우 정보를 한곳에 모아 빠르게 탐색할 수 있습니다.
    
- **💬 참여와 소통**
    
    리뷰와 커뮤니티로 관람 경험을 기록하고 공유합니다.
    
- **⚙️ 안정성과 확장성**
    
    역할 분리 구조와 인증 시스템으로 안정적인 서비스를 제공합니다.

## 🛠️ 기술 스택

### 개발 기술

| 분류 | 기술 |
| --- | --- |
| **Backend** | `Java 17`, `Spring Boot`, `Spring Security`, `JWT`, `MyBatis`, `MySQL` |
| **Frontend** | `Vue.js 3`, `Vite`, `Pinia`, `Vue Router`, `Axios`, `Bootstrap` |
| **Data Crawling** | `Python`, `Selenium`, `BeautifulSoup`  |
| **API 문서화** | `Swagger`  |

### 핵심 기술 적용

| 기능 | 적용 기술 | 설명 |
| --- | --- | --- |
| **인증/인가** | `Spring Security` + `JWT` | Access/Refresh Token 기반의 Stateless 인증 시스템 구축 |
| **데이터베이스 연동** | `MyBatis` | SQL 중심의 유연한 데이터베이스 상호작용 및 쿼리 관리 |
| **데이터 자동 수집** | `Python`, `Selenium` | PlayDB 등 외부 사이트에서 공연 및 배우 정보를 주기적으로 크롤링 |
| **비동기 통신** | `Axios` | 프론트엔드와 백엔드 간의 효율적인 REST API 통신 |
| **상태 관리** | `Pinia` | Vue3 환경에서의 중앙화되고 직관적인 상태 관리 |
